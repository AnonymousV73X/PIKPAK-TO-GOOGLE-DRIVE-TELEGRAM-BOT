How Relay works

What is rclone?

rclone is a free command-line tool that copies and syncs files between cloud storage providers. Relay installs it for you and drives it from this dashboard, so you never touch a terminal. Your credentials stay in a local config file on this machine — they're never sent to any Relay server, because there isn't one.

Setting up PikPak

  1. Run rclone config on any machine (or use an existing config file).
  2. Create a new remote named exactly PIKKY, type PikPak.
  3. Sign in with your PikPak account email and password.
  4. Copy the resulting [PIKKY] block into the setup wizard.

Official rclone PikPak docs ↗

Setting up Google Drive

  1. Create a remote named GDRIVE, type Google Drive.
  2. Follow the OAuth prompt in your browser to authorize access.
  3. Copy the resulting [GDRIVE] block into the setup wizard.

Official rclone Google Drive docs ↗

Setting up WebDAV (free alternative)

WebDAV works with many free or self-hosted storage providers (Nextcloud, Koofr, and others). Just enter your server URL, username, and password in the wizard — no OAuth needed.

Official rclone WebDAV docs ↗

Transfer settings used

Every transfer runs as an rclone sync filtered to video files (mp4, mkv, avi, mov, wmv, flv, webm, mpg, mpeg, m4v, 3gp), with tuning flags: --transfers 4 --checkers 8 --fast-list --checksum --drive-chunk-size 64M --buffer-size 32M. Each run lands in a new timestamped folder so nothing overwrites a previous transfer.

Troubleshooting

  • Install fails: usually a network or firewall block — check your internet connection and try again.
  • Remote verification fails: double check the remote is named exactly PIKKY / GDRIVE / WEBDAV, and that the pasted config block is complete.
  • Transfer stalls: large libraries take time — watch the live log for progress, it updates every few seconds.
  • Wrong destination shown: switch it from the dropdown on the dashboard before starting a transfer.
